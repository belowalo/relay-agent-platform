# Security reporting

Do not include credentials, account records or sensitive reproduction data in public issues. Use the repository's private vulnerability reporting feature when available. Until a private reporting channel is configured, share only a non-sensitive request to arrange one.

Relay encrypts connection credentials and supports workspace roles, MFA and optional organization sign-in. Local tests and a clean dependency audit do not establish production security certification. Review deployment access, HTTPS, data-volume permissions, public application admission, provider quotas and external tools before exposing an instance.

Keep the database and matching vault key together in protected backups. An accepted external action cannot be undone by cancelling a workflow. Uncertain side effects require reconciliation before starting a replacement run.

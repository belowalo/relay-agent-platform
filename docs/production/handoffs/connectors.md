## Recovery and support limits

Connection saves/rotation/disconnection invalidate sync leases; a source selection change needs explicit cursor reset/full reconciliation. In-flight external work cannot be undone, so reauthorize before further work and never replay an uncertain write. Leases renew at fenced item/page operations (60 seconds default, maximum 5 minutes); long inline ingestion requires a bounded queue-based DocumentPort or a longer chosen lease. Crash recovery may leave orphan blobs and must deduplicate document revision upserts.

Drive supports selected files/direct children, native exports and real change cursors; no recursive selection/shortcuts. GitHub files are limited by contents base64 API <=1 MiB; PR mutations are excluded. S3 incremental updates use bounded prefix scans/ETag revisions, without a universal event cursor or automatic absence-based deletion. Provider-confirmed tombstones/custom loaders or explicit removals handle deletion; do not delete from incomplete lists/access errors. MCP uses explicitly selected transport, resources and tool names; no sampling/roots/elicitation callbacks or automatic transport fallback. SQL is read-only only; restricted roles must also exclude external-effect functions. A passing health read certifies only the exercised capability, not every write scope/model feature.

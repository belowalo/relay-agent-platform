# Connector development contract

Keep adapter code under `server/connectors`. Do not import the SQLite DB or decrypt a legacy envelope from a production adapter. Validate strict configuration; reject inline secrets, credential URLs, arbitrary endpoints/methods and invalid selections. Return a frozen v1 descriptor with semver, auth mode, explicit read/write effect, honest idempotency capability and approval requirement. Adding an action/scoping change needs a version review; changing frozen foundation contracts needs coordinator agreement.

Implement `validate(config)`, `descriptor(config)`, `validateInput(config,action,input)`, `invoke(args)`, `testAction`, `testInput` and `testCapabilities`. `invoke` receives verified context, cancellation, `secret()` (authorized current reference), `request()` (policy/deadline/retries/size), ports and trusted idempotency key. Use `request` for HTTP so credential egress and read retry ownership remain centralized. Do not return `headers`, raw URLs containing auth material or provider exception strings. Use `ConnectorError`; write failures must distinguish known rejection from uncertain possible success.

Use `createConnector` for every public invocation. Raw adapter modules are implementation details for trusted composition, never tools exposed to a model. A write descriptor causes the factory to require `actions.execute` and bind the exact cloned arguments/config hash before any external write. Do not classify a remote action as read based solely on MCP annotations or a user-provided flag. Add resource selection checks for every action, including document downloads, search results and pagination.

Pagination returns an opaque `nextCursor`; never follow arbitrary caller URLs. Scope Link URLs to the configured origin/path. Detect repeated cursors and bound pages/items in source synchronization. Incremental watermarks must identify provider consistency semantics: Drive change tokens, S3 listing + ETag, GitHub issue update time or file SHA. Do not claim an ETag always represents a plaintext content hash. Do not delete sources from an incomplete list or a permission error.

Document sources must call DocumentPort with explicit collection/external ID/name/access and scalar metadata. Binary inputs first call BlobPort, then pass its workspace-bound immutable reference. Do not write chunks/vectors or manipulate ingestion tables. Persist cursor/item state after the appropriate port succeeds; use generation fences and reauthorize during recovery. Knowledge must provide revision-aware idempotent upsert; write this requirement into each source adapter's integration notes.

For model adapters, reject unsupported capabilities before sending, bound response bytes/tool counts, validate tool identity/JSON arguments and structured output schema. Require protocol terminal markers and finish reasons. Report missing usage as unknown; quota is not a transient rate limit. Never fallback after any text or tool delta, and do not replay metered generation with unknown execution status. Runtime owns budget reservations/reconciliation.

Required tests include real protocol-shaped fixtures for authentication, forbidden scope, pagination, malformed payloads, partial streams, rate reset, cancellation, deadline, bounded retries, unsafe writes, uncertain outcomes, rotation/revocation, disconnection and cross-workspace references. Test protocol libraries against a real local SDK server when possible. Test PostgreSQL SQL/RLS against an engine, not just string assertions. Label fixture, embedded-engine and live-service evidence separately. Live tests must use selected resources and read-only actions by default; a write test needs explicit authorization and action tracking even if its content is described as a test.

Run `npm run test:connectors`, affected regression tests, types, build and formatting. Provide scopes, nonsecret config examples, setup, limitations and recovery behavior in CONNECTORS.md and update the team handoff. The final branch must identify exact commit/evidence; an adapter's passing fixture tests do not certify the integrated production service.

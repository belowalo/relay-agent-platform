## Material boundaries exercised

- Embedded PostgreSQL executes `0200-security.sql`, forced RLS, foreign-tenant insert rejection, account column privilege rejection and audit-delete rejection with narrow non-owner roles. The harness has one serialized connection: it is **not** evidence of real pooled concurrent transactions or deployment role provisioning.
- Current member/role checks, removed identities, suspended organizations, required MFA/domain policy, owner protection, email-bound one-use invitations and disabled inviter rejection.
- Application grant resource scopes, expiration, revocation, rotation, issuer demotion and dynamic run association; browser cookies/guest receipts cannot authenticate the public API. HTTP stream readers stop after member removal/token rotation; delegated publications/invitations stop after issuer removal.
- Restricted documents deny the owner without an explicit principal grant. An actual HTTP lexical retrieval fixture confirms permitted users receive the document while excluded users receive no candidates; repository checks cover child workflows and connector resources. Complete knowledge exports/caches still require integration.
- Token/cost reservation boundaries, exact idempotent settlement, conflicting settlement rejection, null/unknown costs, uncertain holds, rollover rejection, fenced capacity and stale-capacity reconciliation. In-flight role removal still records actual usage and prevents follow-up output/work.
- Hashed session expiry/idle handling, disabled identities, committed MFA failures, enrollment/TOTP replay prevention, one-use recovery/reset, password change and session invalidation. Synthetic OIDC validates PKCE/browser state/nonce/signature/audience/verified identity and explicit provisioning; synthetic SMTP recovery is exercised separately through local HTTP.
- Credential tenant/version AAD, tamper/wrong-key rejection, revocation, key rewrap and matching backup-key recovery; legacy authenticated envelope migration. HTTP tool cannot forward a stored synthetic credential outside its configured origin/path.
- Raw-body HMAC webhook timestamp/signature/application/delivery binding, replay rejection and rollback-safe enqueue. Local webhook delivery keys reject replay.
- Private IPv4/IPv6/default denial, exact-origin/CIDR capability exceptions, ignored production booleans/deserialized policies, hard-denied metadata/link-local including IPv4-mapped IPv6, DNS rebinding, redirect credential/body protection and response byte caps.
- Upload input/output bounds, format signature rejection, UTF-8 preservation, inert markup extraction and production complex-parser isolation gate.
